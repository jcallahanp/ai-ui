## Rules for steps

- One step produces one thing: a screen, a state of a screen, a token file, a flow.
- A step names every file its agent needs to read. The agent gets nothing else.
- "Done when" is a question a different agent can answer yes or no by looking at the output.
- Each step traces to at least one requirement ID or persona check.
- Status is tracked in `PROGRESS.md`, not here. This file changes only when the plan changes.

## Step format

```
### S01: <short title>
- Do: <the one thing to produce>
- Read: <the files this agent needs, and no others>
- Write: <the files it produces, under design/>
- Covers: <requirement IDs and persona checks, e.g. R3, P1.2>
- Done when: <a yes-or-no check>
```
