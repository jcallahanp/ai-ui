API design

atlas is a small API service for users and their orders. This doc lists the routes, what each one is for and how errors come back, so the handlers and the clients agree on one shape.

Routes

MethodPathPurpose
GET/usersList users, newest first
GET/users/:idGet one user by id
POST/usersCreate a user
PATCH/users/:idUpdate a user's name or email
GET/orders?user_id=List orders, filtered by user

Errors

Every error returns a JSON body with a short code and a message a person can read. The HTTP status matches the code, so clients can check either one.

{
  "error": {
    "code": "user_not_found",
    "message": "No user with id 42.",
    "status": 404
  }
}
